WildCam Sorter v1.9（Mac）使用说明
==================================

一、先确认应该下载哪个版本
--------------------------

点击屏幕左上角“苹果图标 ”→“关于本机”：

1. 如果显示“芯片：Apple M1 / M2 / M3 / M4 / M5……”：
   使用 WildCamSorter_macOS_AppleSilicon_v1.9.zip。

2. 如果显示“处理器：Intel……”：
   使用 WildCamSorter_macOS_Intel_v1.9.zip。

两个版本不能混用。本程序建议在 macOS 13 Ventura 或更高版本运行。


二、安装和第一次运行
--------------------

1. 双击下载的 ZIP，将它完整解压。不要直接在压缩包预览窗口中运行。
2. 打开解压后的文件夹，里面有：
   - WildCamSorter.app（程序）
   - macOS使用说明.txt（本说明）
3. 可以直接运行 WildCamSorter.app，也可以把它拖入“应用程序”文件夹后再运行。
4. 本程序没有经过 Apple 开发者公证，第一次双击时 macOS 可能阻止打开。这不代表程序损坏：
   - 在 Finder 中按住 Control 点击（或右键点击）WildCamSorter.app；
   - 选择“打开”；
   - 在弹出的确认框中再次选择“打开”。
5. 如果仍被阻止：打开“系统设置”→“隐私与安全性”，向下找到关于
   WildCamSorter 的提示，点击“仍要打开”，再按系统提示确认。

不要关闭 macOS 的全部安全保护，也不要对来源不明的软件执行上述操作。
本程序不需要安装 Python，不需要使用终端。


三、首次使用
------------

1. 程序启动后，在设置页选择红外相机数据所在的“输入文件夹”。
2. 选择分类结果保存的“输出文件夹”。输入和输出文件夹不要选成同一个文件夹。
3. 设置相机拍摄模式：每组照片数、视频数，以及照片或视频谁在前面。
4. 点击“确定”，等待程序扫描。大型目录会显示进度，扫描期间可以取消。
5. 看到照片或视频后，使用底部分类按钮完成分类。

程序只会把媒体文件复制到输出文件夹，不会移动或删除原始数据。


四、macOS 权限提示
------------------

- 如果系统询问是否允许访问“桌面”“文稿”“下载”或移动磁盘，请点击“允许”。
- 如果误点了“不允许”，请前往“系统设置”→“隐私与安全性”→“文件与文件夹”，
  给 WildCamSorter 开启相应目录权限，然后重新启动程序。
- 外接硬盘作为输出盘时必须可写。macOS 通常只能读取 NTFS 硬盘，不能直接写入；
  建议使用 APFS、Mac OS 扩展或 exFAT 格式，或选择 Mac 内置磁盘作为输出位置。


五、常见问题
------------

1. 提示“无法验证开发者”或程序被阻止：
   按照本说明第二部分，用右键/Control 点击“打开”，或在“隐私与安全性”中选择“仍要打开”。

2. 双击后没有出现窗口：
   确认下载的芯片版本正确；关闭程序后重新打开，并检查是否有系统权限提示。

3. 视频无法播放：
   先确认该视频能否用 macOS 自带的 QuickTime Player 播放；如果 QuickTime 也无法播放，
   文件可能损坏或编码不受支持。若只有本程序不能播放，请把输出目录中的
   wildcam_sorter.log 发给开发者。

4. 分类结果无法写入移动硬盘：
   检查硬盘是否为 NTFS。可改用 exFAT/APFS 硬盘，或先输出到 Mac 内置磁盘。

5. 可以删除解压出来的文件吗：
   WildCamSorter.app 必须保留；使用说明可以自行保留或删除。分类结果和原始照片
   不依赖安装包，但输出目录中的 .wildcam_progress.json 用于断点续传，请不要删除。
